# Qwen 3 TTS の検証スパイク

Qwen 3 TTSを使った音声生成方法の確認

参考サイト: https://github.com/QwenLM/Qwen3-TTS

## 技術スタック
Pythonの環境はuvで構築
フロントエンドはReactを使用する。 nodeはnvmでインストールしてある。

## Step 01 

Qwen3-TTS の環境構築方法を参照サイトを確認後、指定した技術スタックを用いて実行環境を構築する。

成功した構築方法を技術レポートとして記事を作成する。記事を読んだ人が同じことができるようにわかりやすく書くこと

## Step 02
フロントエンドとバックエンドを接続し、Qwen3-TTSを試行できるプレイグランドアプリケーションを作って
